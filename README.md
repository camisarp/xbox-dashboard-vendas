# Dashboard de Vendas Xbox 🎮

Dashboard de análise de vendas desenvolvido no **Microsoft Excel** no Santander Bootcamp Excel com Inteligência Artificial (DIO).

## Objetivo
Visualizar indicadores de vendas do ecossistema Xbox utilizando gráficos, tabelas dinâmicas e segmentação de dados.

## Arquivo do projeto
📊 [Dashboard Xbox.xlsx](Dashboard%20Xbox.xlsx)

> Abra no Excel para desktop para preservar os elementos interativos. **Arquivo Excel a ser adicionado ao repositório.**

## Estrutura da planilha
- **BASES:** dados de origem.
- **ASSERTS:** recursos visuais e elementos de apoio.
- **CÁLCULOS:** tabelas e cálculos da análise.
- **DASHBOARD:** painel visual de indicadores.

## Recursos
- Tabelas dinâmicas e segmentação de dados
- Gráficos e cartões de indicadores
- Identidade visual inspirada no Xbox

## Como utilizar
1. Baixe `Dashboard Xbox.xlsx`.
2. Abra o arquivo no Microsoft Excel para desktop.
3. Navegue até **DASHBOARD** e explore os filtros.
4. Após alterar a base, atualize as tabelas dinâmicas.
